TAREA 2 — DETECTOR DE INMOVILIDAD Y MORTALIDAD:

Añade un nuevo módulo completo de detección de inmovilidad basado en datos GPS. Es una funcionalidad nueva que analiza el movimiento de los animales para detectar posible mortalidad. Está basado en un script Python que teníamos en Google Colab + N8N, pero ahora lo integramos directamente en la web.

A) NUEVO ARCHIVO: server/immobilityDetector.ts

Crea una clase ImmobilityDetector con esta lógica:

interface ImmobilityConfig {
  hoursToAnalyze: number;          // default 96 (últimas 4 días)
  immobilityThresholdHours: number; // default 24 (horas inmóvil para alerta)
  noTransmissionThresholdHours: number; // default 48
  speedThreshold: number;          // default 0.5 m/s
  positionChangeThreshold: number; // default 0.0001 grados (~11 metros)
}

La clase debe:

1. prepareData(gpsEvents): Recibe array de GPS events de cached_gps_events. Ordena por animal y timestamp. Calcula para cada punto consecutivo del mismo animal:
   - time_diff: diferencia en horas con el punto anterior
   - distance: distancia en grados entre puntos consecutivos (sqrt((lat2-lat1)² + (lon2-lon1)²))
   - speed_calculated: si ground_speed es 0 o null, calcular distance/time_diff convertido a m/s aproximado (1 grado ≈ 111320 metros)

2. detectImmobility(preparedData): Para cada punto, marca is_immobile = true si:
   - speed < speedThreshold (0.5 m/s) Y
   - distance < positionChangeThreshold (0.0001°)
   Agrupa períodos consecutivos de inmovilidad del mismo animal con un immobility_group_id

3. identifyMortalityEvents(analyzedData): Para cada grupo de inmovilidad:
   - Calcula duración total del grupo (timestamp_max - timestamp_min)
   - Si duración >= immobilityThresholdHours → genera alerta de MORTALIDAD con:
     * individual: nombre del animal
     * species: especie
     * alertStart: inicio del período inmóvil
     * alertEnd: último punto inmóvil
     * hoursImmobile: duración
     * daysImmobile: duración en días
     * numRecords: puntos en el período
     * lastLat, lastLon: última posición conocida
     * avgSpeed, maxSpeed: velocidades del período
     * googleMapsUrl: https://www.google.com/maps?q={lat},{lon}
     * status: "INMÓVIL"
     * severity: "critical" si > 48h, "warning" si > 24h

4. checkTransmissionStatus(individuals, gpsEvents): Para cada animal del estudio:
   - Busca su última transmisión en los datos GPS
   - Si no tiene datos GPS en el rango analizado, busca el último dato en toda la caché
   - Si horas desde última transmisión >= noTransmissionThresholdHours → alerta de SIN TRANSMISIÓN con:
     * individual, species, lastTransmission, hoursSinceLast, daysSinceLast, status: "SIN TRANSMISIÓN"
     * severity: "critical" si > 96h, "warning" si > 48h

5. analyze(studyId, config): Función principal que:
   - Lee los individuos del estudio con deployment activo
   - Lee los datos GPS de cached_gps_events de las últimas config.hoursToAnalyze horas
   - Ejecuta prepareData → detectImmobility → identifyMortalityEvents + checkTransmissionStatus
   - Guarda las alertas en la tabla detected_events con event_type = 'mortality' o 'no_transmission'
   - Devuelve { summary, immobilityAlerts, noTransmissionAlerts, stats }
